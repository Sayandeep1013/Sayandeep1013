#### Featured

| Project | What it is |
|---|---|
| [Symbiote](https://github.com/Sayandeep1013/Symbiote) | An interactive WebGL "digital organism" — a floating, glossy black creature that reacts to the cursor. Frontend-only, Three.js. |
| [Tessera](https://github.com/Sayandeep1013/Tessera) | A code-native pixel-art editor with an AI editing agent — every pixel is a readable/hand-editable JSON index, and the AI proposes structured pixel-diffs you can accept or reject. |
| [DroidDoodle](https://github.com/Sayandeep1013/DroidDoodle) | An offline Android app where an on-device small language model manipulates a visual canvas through tool calls — a learning lab for agentic AI as much as a creative toy. |
| [Mubitracker](https://github.com/Sayandeep1013/mubitracker-watchdeck) | A frictionless personal media memory system — track movies, TV, and anime with one decision per title. Next.js + Expo + Supabase. |

| [Picaku STT Demo](https://github.com/Sayandeep1013/Trans_Cribed) | On-device English transcription spike (sherpa-onnx + Silero VAD) — live captions, fully offline after a one-time model download. |
